게임 규칙
  • 방장이 시작하면 모든 참가자에게 같은 시작 문서와 목표 문서가 랜덤으로 주어져요.
  • 나무위키 문서 본문의 링크만 클릭해서 목표 문서까지 이동하세요.
  • 검색창, 주소창 직접 입력, 뒤로가기는 금지예요.
  • 타임어택: 가장 빨리 도착한 사람이 1등이에요.
  • 최소 클릭: 가장 적은 클릭으로 도착한 사람이 1등이에요. 클릭 수가 같으면 더 빨리 도착한 사람이 이겨요.
  • 확장 프로그램이 나무위키에서 누른 링크와 도착을 자동으로 기록해요. 링크 클릭이 아닌 이동(검색, 주소창, 뒤로가기)은 ⚠️로 표시돼요.
  • 결과 화면에서 모든 사람의 경로가 공개돼요.
🧩 자동 기록 확장 프로그램 설치 (PC 크롬/엣지)

✅ 이 브라우저에는 이미 설치되어 있어요.

  1. 이 링크로 ZIP 파일을 내려받아 압축을 풀어요.
  2. 주소창에 chrome://extensions를 입력해요. 엣지라면 edge://extensions예요.
  3. 오른쪽 위(엣지는 왼쪽)의 개발자 모드를 켜요.
  4. 압축해제된 확장 프로그램을 로드합니다를 누르고, 압축을 푼 폴더 안의 extension 폴더를 선택해요.
  5. 이 페이지를 새로고침해요.

모바일 브라우저는 확장 프로그램을 지원하지 않아요. 모바일에서는 직접 경로를 적는 수동 기록으로 참가해요.
