# 나무위키 레이스 🏁

친구들과 **같은 시작 문서 → 목표 문서**를 받아 나무위키 링크만 타고 누가 먼저(또는 적은 클릭으로) 도착하는지 겨루는 게임입니다.

- 화면: GitHub Pages(정적 사이트)
- 실시간 방/순위 동기화: Firebase Realtime Database

## 회원과 포인트
- **로그인해야 게임할 수 있습니다.** 이름, 닉네임, 아이디, 비밀번호(6자 이상)로 가입하면 **바로 이용**할 수 있습니다. 로그인할 때 아이디와 비밀번호를 입력합니다. 이름은 본인과 관리자만 볼 수 있습니다.
- **부정행위 막기**: ① 자동 조종 브라우저(셀레니움 같은 봇, `navigator.webdriver`)에서는 게임 페이지가 준비·시작을 막고, 확장 프로그램은 그 레이스를 바로 실격시킵니다. ② 프로그램이 누른 클릭(사람이 누르지 않은 클릭)은 확장 프로그램이 막고 규칙 위반 1회로 셉니다(문서마다 1회, 2회면 실격, 확장 프로그램 1.9.0). ③ 같은 계정은 방 하나에 창 하나만: 다른 창·기기에서 같은 방에 들어오면 먼저 있던 창은 방에서 나갑니다(참가 기록의 `sid`). 작정하고 숨긴 봇이나 컴퓨터의 다른 프로그램은 브라우저가 볼 수 없어서 막지 못합니다.
- **방 비밀번호**: 방장이 설정에서 **🔒 비밀번호 걸기**를 켜고 숫자 4자리를 저장하면, 새로 들어오는 사람은 비밀번호를 입력해야 합니다(이미 있는 사람·새로고침해서 다시 들어오는 사람은 그대로). 비밀번호는 `roomPw/<코드>`에 있고 방장만 읽을 수 있으며, 서버 규칙이 들어오는 사람이 `roomKeys/<코드>/<uid>`에 쓴 값과 같을 때만 참가를 허용합니다(2초에 한 번만 시도 가능). 시작 화면 방 목록에 🔒가 붙습니다.
- **게스트로 하기**: 로그인 화면 아래에서 이름만 쓰고 바로 할 수 있습니다(이름 뒤에 `(게스트)`가 붙음). 방 만들기·참가·게임·채팅만 되고, 캐릭터는 고양이로 고정이며 포인트·상점·퀘스트·오늘의 챔피언은 회원만 씁니다. Firebase **Authentication → 로그인 방법 → 익명**을 켜야 합니다. 게스트는 회원 정보가 만들어지지 않고(규칙에서도 막음), '로그인 / 회원가입'이나 로그아웃을 누르면 게스트 계정이 지워집니다. 게스트 로그인과 이름은 그 탭에만 저장되어 새로고침하면 그대로지만 창을 닫으면 사라집니다(Firebase 사용자 목록에는 빈 익명 계정이 남을 수 있음). 게스트는 **1시간**까지 할 수 있고(`GUEST_LIMIT_MS`), 시간이 지나면 게스트 화면이 스스로 방에서 나가고 게스트 계정을 지웁니다(달리는 중이면 판이 끝난 뒤). 창을 닫고 나간 게스트는 방장이 5초(게임 중 60초) 뒤 방에서 지워서 캐릭터가 남지 않습니다. 창을 닫아 남은 빈 익명 계정은 다시 쓸 수 없고, 서버 없이는 자동으로 지울 수 없어서 가끔 콘솔에서 지웁니다. 회원 닉네임에는 '게스트'을 쓸 수 없습니다.
- **예전 계정(아이디만으로 가입)**: 비밀번호 칸을 비우고 로그인하면 '비밀번호 만들기' 화면이 나오고, 비밀번호를 만들어야 게임을 할 수 있습니다(`users/<uid>/pwSet`). 비밀번호를 만들기 전까지는 아이디만 알면 누구나 그 계정으로 들어갈 수 있으니 빨리 만들어야 합니다. 관리자 페이지의 회원 목록에 '비밀번호 없음'으로 표시되고, 관리자 계정은 비밀번호를 만들어야 관리자 페이지가 열립니다. 관리자 페이지는 비밀번호와 함께 찾기 질문이 없는 회원도 '찾기 질문 없음'으로 보여 줍니다.
- **비밀번호 찾기 (질문 1개, `recovery.js`)**: 가입할 때(예전 계정은 비밀번호를 만들 때) 질문 1개를 고르고 답합니다(질문 목록은 `QUESTIONS`, 혈액형·전화번호 뒷자리처럼 남이 쉽게 아는 질문은 뺌). 로그인 화면의 **비밀번호를 잊었어요**에서 아이디와 같은 질문에 답하면(띄어쓰기·대소문자 무시) 새 비밀번호로 바꿉니다. 프로필에서 **비밀번호 바꾸기**와 **찾기 질문 바꾸기**를 할 수 있습니다. 찾기 질문 바꾸기는 그 기기에서 비밀번호로 로그인한 적이 있으면 비밀번호를 묻지 않습니다(비밀번호를 그 브라우저 안에서만 꺼낼 수 없는 열쇠로 잠가 보관, 로그아웃하면 지움). 예전 질문 2개 방식으로 만든 사람은 프로필에서 다시 만들라는 안내가 뜹니다(`users/<uid>/rcvV`).
  - 서버 없이 동작하는 방식: 비밀번호를 질문+답으로 만든 열쇠로 잠가 `vault/<uid>`에 저장합니다. `vault`는 본인과 '찾기용 계정'(`<아이디>.rcv@namurace.app`, 비밀번호도 질문+답으로 만듦)만 읽을 수 있어서, 질문이나 답이 틀리면 열 수 없고 Firebase가 여러 번 틀린 시도를 막습니다. `keys/<uid>`에는 그 열쇠를 내 비밀번호로 잠가 두어 비밀번호를 바꿀 때 다시 잠급니다. 관리자도 답이나 비밀번호를 모르면 열 수 없습니다.
  - 답을 아는 사람은 비밀번호를 찾을 수 있으니, 친구가 맞히기 쉬운 답은 피하라고 안내합니다.
- 시작 화면에 내 포인트와 기록(게임 수, 🥇🥈🥉 횟수, 👑 오늘의 챔피언 1등 횟수)이 나옵니다.
- **승리 포인트**: 참가 인원에 따라 받습니다. 2명이면 1등 30점, 3명이면 1등 50점·2등 30점, 4명 이상이면 1등 100점·2등 50점·3등 30점입니다.
- **오늘의 챔피언 포인트**: 하루가 지나면 그날 1·2·3등에게 200·150·100점을 줍니다.
- **부적절한 단어 거르기** (`badwords.js`): 채팅의 욕설·비속어는 `***`로 바뀌고(보낼 때와 화면에 그릴 때 모두), 닉네임에는 쓸 수 없습니다. 글자 사이에 띄어쓰기·숫자·기호를 넣어도 걸러지고, '시발점'·'새끼손가락' 같은 평범한 말은 그대로 둡니다. 거를 단어는 `WORDS`, 걸리면 안 되는 말은 `ALLOW`에 더하면 됩니다.
- **닉네임은 한 사람만**: 다른 사람이 쓰는 닉네임으로는 가입하거나 바꿀 수 없습니다(대소문자·띄어쓰기만 다른 것도 같은 닉네임). 닉네임 목록은 `nicks`에 있습니다. 예전에 같은 닉네임으로 가입한 사람은 먼저 로그인한 사람이 그 닉네임을 갖고, 나중 사람에게는 무료로 한 번 바꿀 수 있다는 안내가 뜹니다.
- **닉네임 변경**: 300포인트를 쓰고 바꿉니다. 닉네임은 8글자까지 쓸 수 있습니다(예전에 만든 더 긴 닉네임은 그대로 유지).
- **오늘의 퀘스트** (오늘의 챔피언 아래): 맨 위의 **출석하기**(30P)는 매일 들어오기만 하면 받을 수 있습니다. 그 아래로 매일 자정(한국 시간)에 난이도별로 ★ 2개(30P), ★★ 1개(50P), ★★★ 1개(80P)가 정해집니다(모두 같은 퀘스트). ★는 오늘 3판 하기·오늘의 문제 도착하기·릴레이 모드 완주하기·힌트 없이 완주하기·최소 클릭 모드 완주하기·타임어택 모드 완주하기·5분 안에 도착하기, ★★는 1등 하기·오늘 5판 하기·세 모드 모두 완주하기·3분 안에 도착하기, ★★★는 1등 3번 하기·오늘의 챔피언 3등 안에 들기·오늘 10판 하기·2분 안에 도착하기 중에서 매일 돌아가며 나옵니다. 도착 시간은 힌트 페널티를 포함한 기록으로 봅니다. 달성하면 **받기**를 눌러 포인트를 받습니다. 판 수는 목표까지 완주한 판만, 1등은 3명 이상인 방에서만 셉니다. 서버 규칙이 오늘의 퀘스트를 하루 한 번씩만 받게 막습니다(출석 포함 하루 최대 220P).
- **상점** (시작하기 카드 오른쪽 위 🛒): 포인트로 캐릭터(500P)와 액세서리(300P)를 삽니다. 처음에는 고양이만 쓸 수 있고 나머지는 잠겨 있습니다. **우주 상어**는 헬멧을 쓰고 있어서 액세서리를 착용할 수 없습니다 (착용해 둔 액세서리는 다른 캐릭터로 바꾸면 다시 보입니다). 액세서리는 모자·안경·목·옷·신발·가방 부위마다 하나씩 착용합니다 (16종). 산 것은 계정에 저장되어 어느 방에서나 쓸 수 있습니다.
- **관리자 페이지**(`admin.html`, 로그인하면 위쪽에 "관리자" 링크): 회원 목록, 포인트 조정, 이용 정지, 삭제.

### 처음 설정 (Firebase 콘솔)
1. **Authentication → 시작하기 → 로그인 방법 → 이메일/비밀번호**를 사용 설정합니다. (아이디는 내부적으로 `아이디@namurace.app` 형태의 이메일로 저장됩니다.)
2. **Authentication → 설정 → 승인된 도메인**에 `yeowon811.github.io`가 있는지 확인하고 없으면 추가합니다.
3. **Realtime Database → 규칙**에 `database.rules.json`을 붙여넣고 게시합니다.
4. 게임에서 내 계정으로 가입합니다.
5. **Realtime Database → 데이터**에서 루트에 `admins` → `<내 uid>: true`를 추가하면 관리자가 됩니다. (uid는 Authentication → 사용자 목록에서 볼 수 있습니다.)

> 포인트는 데이터베이스 규칙으로 보호합니다. 남의 포인트는 지급 기록 없이 올릴 수 없고, 같은 판의 승리 포인트는 한 번만 받을 수 있습니다. 다만 서버 없이 동작하기 때문에 완벽한 조작 방지는 아닙니다.

## 게임 방식
- 방장이 방을 만들고 초대 링크를 공유합니다. 초대 링크로 들어오면 "초대받은 방 참가하기" 버튼이 보입니다.
- 시작 화면의 **열려 있는 방** 목록에서 바로 참가할 수도 있습니다. 방장은 설정에서 "방 목록에 공개"를 꺼서 방을 숨길 수 있습니다.
- 모드
  - **⏱️ 타임어택**: 가장 먼저 도착한 사람이 이기고, 1등이 나오는 순간 게임이 끝납니다. 설정의 **게임 종료**에서 2등이나 3등까지 나오면 끝나도록 바꿀 수 있습니다. 릴레이도 같습니다.
  - **👆 최소 클릭**: 가장 적은 클릭으로 도착한 사람이 1등이고, 클릭 수가 같으면 더 빨리 도착한 사람이 이깁니다.
  - **🔗 릴레이**: 목표가 2~5곳이고 하나씩 공개됩니다. 예: `너구리 → 일본 → 타지마할`. 지금 목표에 도착해야 다음 목표가 나오고, 모든 목표를 가장 먼저 지나간 사람이 이기며 그 순간 게임이 끝납니다. 확장 프로그램 1.3.0 이상이 필요합니다. **마지막에 시작 문서로 돌아오기**를 켜면 `너구리 → 일본 → 타지마할 → 너구리`처럼 마지막 목표가 시작 문서가 됩니다. 다른 사람이 몇 번째 목표까지 갔는지는 현황판과 나무위키 탭의 실시간 순위에 점(●●○)으로 표시됩니다.
- 제한 시간을 정할 수 있습니다. 제한 없음, 3분, 5분, 10분, 15분, 20분, 30분 중에서 고릅니다.
- 시작하면 3초 카운트다운 뒤에 모두에게 같은 키워드가 공개됩니다.
- 실제 나무위키(namu.wiki)에서 플레이합니다.
- **자동 기록(확장 프로그램 설치 시)**: 게임 화면의 "나무위키에서 열기"를 누르면 확장 프로그램이 레이스용 탭을 엽니다. 그 탭에서 누른 링크, 클릭 수, 도착 시각이 자동으로 기록되고, 목표 문서에 들어가는 순간 도착 처리됩니다.
  - **규칙 위반 제재 (확장 프로그램 1.5.0)**: 링크 클릭이 아닌 이동(브라우저 뒤로가기, 주소창 입력 등)은 감지하는 즉시 **원래 문서로 되돌리고** 위반 1회로 셉니다. **Ctrl+F / F3 (찾기)**는 막히고, 시도하면 위반 1회입니다(문서마다 1회). **위반 2회면 실격**되고 포인트를 받지 못합니다. 레이스 중 다른 탭이나 창을 3초 넘게 보면 경고가 뜨고 결과에 횟수가 표시됩니다.
  - **↩ 이전 문서로** 버튼은 본문에 누를 수 있는 다른 문서 링크가 하나도 없는 **막다른 문서**(없는 문서, 삭제된 문서 등)에서만 켜집니다 (확장 프로그램 1.7.0). 규칙 위반이 아니고 클릭 1번으로만 셉니다. 오른쪽 '최근 변경' 목록, 목차·각주 같은 같은 문서 안 링크는 누를 수 있는 링크로 치지 않고, 분류 링크는 누를 수 있는 링크로 칩니다.
  - 목표 문서를 모르겠으면 **💡 힌트** 버튼으로 위키백과 요약을 볼 수 있습니다. 페널티: 타임어택·릴레이·오늘의 챔피언은 **+30초**, 최소 클릭은 **+3클릭** (릴레이는 목표마다 따로). 확장 프로그램 1.4.0 이상.
   - **힌트 카운트다운**: 타임어택·릴레이에서 힌트를 쓴 사람이 마지막 등수(1등만이면 1등, 3등까지면 3등)를 채우며 도착하면 바로 끝나지 않고, 붙은 페널티 시간(힌트 1번에 30초)만큼 카운트다운이 돌아갑니다. 그 안에 다른 사람이 도착해서 더 좋은 기록을 내면 앞서고, 아무도 못 하면 힌트를 쓴 사람의 순위가 확정되며 게임이 끝납니다. 게임 화면과 나무위키 화면(확장 프로그램 1.8.0 이상)에 남은 시간과 안내가 보이고, 실시간 순위에는 힌트를 쓴 사람 옆에 💡가 붙습니다.
  - **💬 레이스 중 채팅 (확장 프로그램 1.6.0)**: 나무위키 탭 상자 맨 위의 채팅창에서 같은 방 사람들과 대화할 수 있습니다. 이번 판에서 나눈 대화 중 최근 5개만 보이고, 판이 시작할 때는 비어 있습니다. 채팅창을 접어 두면 새 메시지가 왔을 때 숫자와 알림이 뜨고, 누르면 펼쳐집니다. 레이스 중에 나눈 대화는 대기실 채팅에도 남습니다.
  - 넘겨주기(리다이렉트) 문서도 인정됩니다. 예를 들어 목표가 `BTS`면 `방탄소년단`에 도착해도 됩니다.
  - 레이스 탭에서는 나무위키 **검색창(자동완성 포함)과 랜덤 문서가 막힙니다.** 도착하면 다시 풀립니다.
  - 나무위키 탭 오른쪽 아래에 목표 문서, 클릭 수, 시간, **실시간 순위**가 표시되고, 누가 도착하면 오른쪽 위에 알림이 뜹니다.
- **수동 기록(확장 프로그램 없음, 모바일)**: 도착하면 **도착했어요!**를 누르고 거쳐간 문서를 직접 적습니다. 결과에 **✍️ 수동 기록**으로 표시됩니다.
- 게임이 끝나면 게임 탭과 나무위키 탭 가운데에 **게임 완료!** 알림과 1등이 표시됩니다.
- 대기실에는 **광장**이 있습니다. 각자 가진 동물 캐릭터와 액세서리를 고르고(상점에서 산 것만), **방향키나 WASD**(휴대폰은 화면의 방향 버튼, 또는 바닥을 눌러서)로 걸어 다니고, **Shift**를 누른 채 움직이면 달리고 **Space**로 점프하고(휴대폰은 달리기·점프 버튼), 채팅하면 머리 위에 말풍선이 뜹니다. 대화는 최근 60개까지 남습니다. 캐릭터는 걷는 방향에 따라 앞·옆·뒷모습으로 바뀝니다. 그림은 `img/` 폴더에 있습니다. 캐릭터는 앞·뒤·왼쪽·오른쪽 그림이 있고, 옆으로 걸을 때는 두 장을 번갈아 보여줍니다. 액세서리 그림은 `img/acc/`에 있고, 동물·방향마다 어디에 얹을지는 `animals.js`의 `ANCHORS`에 있습니다. 옷(후드티·레인코트·멜빵바지·멜빵 원피스)은 위에 얹지 않고 옷 입은 캐릭터 그림(`img/animals/outfit/{동물}-{방향}-{옷}.webp`, 기본 그림 둘레에 30px 여백)으로 통째로 바꿔 보여줍니다. 지금은 모자·옷·가방 부위만 켜져 있습니다.
- **🏆 오늘의 챔피언**: 날마다(한국 시간) 모두에게 같은 문제 1개가 나옵니다. 시작 문서와 목표 2곳으로 이루어져 있고, 목표는 릴레이처럼 하나씩 공개됩니다. 시작 화면에서 혼자 도전하고, 가장 빠른 기록이 남으며 상위 3명이 표시됩니다. 확장 프로그램으로 자동 기록되고 링크 클릭이 아닌 이동이 없는 기록만 순위에 오릅니다.
- 결과 화면에서 모든 사람의 경로가 공개됩니다.
- 방장은 참가자 목록의 내보내기 버튼으로 참가자를 내보낼 수 있습니다. 내보낸 사람은 그 방에 다시 들어올 수 없습니다.
- 새로고침해도 같은 방으로 자동 복귀합니다. 방장이 30초 넘게 나가 있으면 다음 사람이 방장을 이어받습니다.

랜덤 키워드 목록은 `keywords.js`에서 자유롭게 추가하거나 삭제할 수 있습니다. 나무위키 문서 제목과 똑같이 적어야 합니다.

## 🧩 자동 기록 확장 프로그램 설치
PC의 크롬 또는 엣지에서만 됩니다.
1. 크롬 웹 스토어의 [나무위키 레이스 도우미](https://chromewebstore.google.com/detail/%EB%82%98%EB%AC%B4%EC%9C%84%ED%82%A4%20%EB%A0%88%EC%9D%B4%EC%8A%A4%20%EB%8F%84%EC%9A%B0%EB%AF%B8/cdlcmcpihomfmnebgjakgmaecegmphap) 페이지를 엽니다.
2. **Chrome에 추가** → **확장 프로그램 추가**를 누릅니다. (엣지는 먼저 **다른 스토어의 확장 허용**을 누릅니다.)
3. 게임 페이지를 새로고침합니다. 홈 화면의 설치 안내에 "✅ 이미 설치되어 있어요"가 보이면 성공입니다.

웹 스토어로 설치하면 업데이트는 자동으로 됩니다. 예전에 ZIP 파일(압축해제된 확장 프로그램)로 설치했다면 `chrome://extensions`에서 먼저 삭제하세요. 둘 다 켜져 있으면 기록이 꼬일 수 있습니다.

개발할 때는 `extension` 폴더를 **개발자 모드 → 압축해제된 확장 프로그램을 로드합니다**로 직접 로드해서 시험할 수 있습니다. 고친 뒤에는 `manifest.json`의 버전을 올려서 웹 스토어에 다시 올립니다.

**확장 프로그램 1.8.0 이상이 필요합니다.** 예전 버전이 설치되어 있으면 게임 준비·시작과 오늘의 챔피언 도전이 막히고, 방에 들어오면 '버전 업데이트를 진행해 주세요' 창과 준비 막대의 **업데이트 방법** 버튼이 뜹니다. 준비할 때 확장 프로그램 버전도 함께 보내서, 예전 화면에서 준비한 사람은 방장 화면에 '업데이트 필요'로 보이고 시작할 수 없습니다. 최소 버전은 `app.js`의 `EXT_MIN`에서 바꿉니다.

## 파일 구성
| 파일 | 역할 |
| --- | --- |
| `index.html`, `style.css`, `app.js` | 게임 화면과 로직 |
| `keywords.js` | 랜덤 키워드 목록 |
| `firebase-config.js` | Firebase 프로젝트 설정 |
| `database.rules.json` | Realtime Database 보안 규칙 (콘솔에 붙여넣기용) |
| `extension/` | 자동 기록 크롬 확장 프로그램 (`tracker.js`: 기록 규칙, `namu.js`: 나무위키 탭 감지·표시, `game.js`: 게임 페이지 연결) |
| `dev-server.js` | 내 PC에서 테스트할 때만 쓰는 간단한 서버 |

## 1. Firebase 설정
1. `firebase-config.js`의 `apiKey: 'YOUR_API_KEY'`를 Firebase 콘솔의 실제 apiKey 값으로 바꿉니다. 콘솔의 프로젝트 설정 → 일반 → 내 앱에서 볼 수 있습니다.
2. Firebase 콘솔 → **Realtime Database → 규칙** 탭에 `database.rules.json` 내용을 붙여넣고 **게시**를 누릅니다.
   - 이 규칙은 `rooms/방코드` 아래만 읽고 쓸 수 있게 합니다. 전체 방 목록은 볼 수 없습니다.

## 2. 내 PC에서 테스트
```bash
npm run dev
```
http://localhost:5500 을 엽니다. ES 모듈을 쓰기 때문에 `index.html`을 더블클릭해서 열면 동작하지 않습니다.

## 3. GitHub Pages로 배포
```bash
git init
git add .
git commit -m "나무위키 레이스"
git branch -M main
git remote add origin https://github.com/yeowon811/namuwiki-game.git
git push -u origin main
```

2. Source를 **Deploy from a branch**로, Branch를 **main / (root)**로 정하고 Save를 누릅니다.
3. 1~2분 뒤 **https://yeowon811.github.io/namuwiki-game/** 에서 게임이 열립니다.

## 참고
- **보안 규칙 요약** (`database.rules.json`): 방의 참가자 기록은 본인·방장·관리자만 고칠 수 있고, 숫자 칸(클릭 수·힌트 수 등)에는 숫자만 들어갑니다. 방을 고치려면 그 방 참가자여야 하고, 방 지우기·내보내기·방 닫기는 방장(또는 오래된 방 정리)만 할 수 있습니다. 순위 보상(1~3등 포인트)은 하루 20번까지입니다(`app.js`의 `WIN_CAP`과 규칙의 숫자를 같이 바꿔야 함). 화면에 그릴 때도 방 데이터의 숫자 칸을 한 번 더 검사합니다(`cleanPlayer`, `cleanRoom`).
- 게임 기록(시간·클릭 수)과 오늘의 챔피언 기록은 각자의 화면이 보내는 값을 믿습니다. 완전히 막으려면 서버 프로그램(Firebase Cloud Functions, 유료 요금제)에서 기록을 확인해야 합니다.
- 웹용 Firebase apiKey는 비밀번호가 아니라 공개되어도 되는 값입니다. 다만 다른 사이트에서 쓰지 못하게 하려면, Google Cloud 콘솔 → API 및 서비스 → 사용자 인증 정보에서 해당 키의 **HTTP 리퍼러 제한**에 `yeowon811.github.io/*`와 `localhost:5500/*`를 추가하세요.
- **준비(레디)**: 방장이 아닌 사람은 대기실과 결과 화면에서 **준비하기**를 누릅니다. 접속 중인 사람이 모두 준비해야 방장이 게임을 시작(다음 판)할 수 있습니다. **자동 준비**에 체크해 두면 매 판 자동으로 준비됩니다. 새 판이 시작되면 준비가 풀립니다.
- **게임을 시작하지 않는 방 자동 닫기**: 방을 만든 뒤(또는 마지막 판이 끝난 뒤) **30분 동안 게임을 시작하지 않으면** 방장 화면이 방을 자동으로 닫습니다. 닫히기 5분 전부터 대기실과 결과 화면에 안내가 뜨고, 게임을 시작하면 다시 30분이 늘어납니다.
- **방 데이터 자동 정리**: 방장이 1분마다 방의 마지막 활동 시각(`roomIndex`)을 남깁니다. 2시간 넘게 활동이 없는 방, 닫힌 방, 활동 기록이 없고 접속자도 없는 예전 방, 방장·상태가 없는 빈 조각은 누군가 시작 화면에 들어올 때 자동으로 지워집니다(모두 합쳐 30분에 한 번). 관리자 페이지의 **데이터 정리 → 지금 정리**로 바로 지울 수도 있고, 활동 기록이 없는 예전 방도 접속자가 없으면 함께 지워집니다.
- 확장 프로그램은 레이스 탭 하나만 기록합니다. 다른 탭에서 문서를 미리 찾아보는 것까지는 막을 수 없습니다. 수동 기록도 본인이 적은 경로를 그대로 믿습니다.
